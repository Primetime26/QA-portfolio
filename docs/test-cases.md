# Приоритетные тест-кейсы

Общие предусловия: доступ в интернет, сервис `https://dummyjson.com` отвечает, клиент принимает JSON.

## TC-API-001 — Получение первой страницы товаров

**Приоритет:** P0  
**Шаги:** отправить `GET /products?limit=5&skip=0&select=title,price`.  
**Ожидаемый результат:** код `200`; ответ — JSON; `products` содержит 5 элементов; `limit = 5`, `skip = 0`; у каждого товара есть числовой `id`, строковый `title` и числовой `price`.

## TC-API-002 — Получение существующего товара

**Приоритет:** P0  
**Шаги:** отправить `GET /products/1`.  
**Ожидаемый результат:** код `200`; `id = 1`; `title` — непустая строка; `price` — положительное число.

## TC-API-003 — Запрос несуществующего товара

**Приоритет:** P1  
**Шаги:** отправить `GET /products/999999`.  
**Ожидаемый результат:** код `404`; ответ — валидный JSON с понятным сообщением; отсутствуют stack trace и внутренние пути сервера.

## TC-API-004 — Добавление товара

**Приоритет:** P1  
**Тестовые данные:** `title = QA Portfolio Test Product`, `price = 19.99`.  
**Шаги:** отправить `POST /products/add` с JSON-телом и заголовком `Content-Type: application/json`.  
**Ожидаемый результат:** код `201`; ответ содержит положительный числовой `id`; `title` и `price` равны переданным значениям. Повторный GET не выполняется, потому что сервис не сохраняет изменения.

## TC-API-005 — Частичное изменение товара

**Приоритет:** P1  
**Тестовые данные:** `title = QA Portfolio Updated Product`.  
**Шаги:** отправить `PATCH /products/1` с JSON-телом.  
**Ожидаемый результат:** код `200`; `id = 1`; `title` равен переданному значению; ответ является валидным JSON.

## TC-API-006 — Удаление товара

**Приоритет:** P1  
**Шаги:** отправить `DELETE /products/1`.  
**Ожидаемый результат:** код `200`; `id = 1`; `isDeleted = true`; `deletedOn` содержит валидную дату и время.

## TC-API-007 — Поиск без совпадений

**Приоритет:** P2  
**Шаги:** отправить `GET /products/search?q=zzzz-no-match-qa-portfolio`.  
**Ожидаемый результат:** код `200`; `products` — пустой массив; `total = 0`; сервис не возвращает `5xx`.
