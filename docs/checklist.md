# Чек-лист API каталога товаров

Статус здесь не проставлен намеренно: это повторно используемый набор проверок, а не отчёт о конкретном прогоне.

## Доступность и контракт

- [ ] API отвечает по HTTPS.
- [ ] Ответы имеют `Content-Type: application/json`.
- [ ] Тело каждого успешного ответа — валидный JSON.
- [ ] Необработанные ошибки и stack trace не попадают в ответ.
- [ ] Для ключевых запросов время ответа не превышает 2 секунд в обычных условиях.

## Получение списка

- [ ] `GET /products` возвращает `200` и массив `products`.
- [ ] Каждый товар содержит числовой `id`, строковый `title` и числовой `price`.
- [ ] `limit=1` возвращает не более одного элемента.
- [ ] `limit=5&skip=5` корректно отражает параметры пагинации.
- [ ] `limit=0` обрабатывается согласно документации.
- [ ] `select=title,price` ограничивает набор полей.
- [ ] Отрицательный и нечисловой `limit` не приводят к `5xx`.

## Получение товара

- [ ] Существующий ID возвращает `200` и тот же `id` в теле.
- [ ] Несуществующий ID возвращает `404`.
- [ ] `0`, отрицательный ID и строковый ID не приводят к `5xx`.
- [ ] Повторный одинаковый GET возвращает согласованный результат.

## Поиск

- [ ] Существующая подстрока возвращает релевантные товары.
- [ ] Поиск без совпадений возвращает пустой массив и `total = 0`.
- [ ] Пустой запрос обрабатывается предсказуемо.
- [ ] Кириллица и URL-кодированные спецсимволы не приводят к `5xx`.

## Создание и изменение

- [ ] `POST /products/add` возвращает созданный объект и новый `id`.
- [ ] Переданные `title` и `price` отражаются в ответе.
- [ ] `PATCH /products/{id}` меняет только переданные поля в ответе.
- [ ] Пустое тело и неверный `Content-Type` не приводят к внутренней ошибке сервера.
- [ ] Числовые, нулевые, отрицательные и строковые значения `price` проверены исследовательски.

## Удаление

- [ ] `DELETE /products/{id}` возвращает ID удаляемого объекта.
- [ ] Ответ содержит `isDeleted = true`.
- [ ] `deletedOn` имеет формат даты и времени.
- [ ] Удаление неизвестного ID не приводит к `5xx`.

## Безопасность на базовом уровне

- [ ] Сообщения об ошибках не раскрывают внутренние пути и конфигурацию.
- [ ] Строковые поля безопасно обрабатывают HTML/JS-подобный ввод.
- [ ] Query-параметры безопасно обрабатывают кавычки и SQL-подобные строки.

Глубокое security-тестирование не входит в объём демонстрационного проекта.
