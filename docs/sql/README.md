# SQL-проверки каталога и заказов

Файл [`queries.sql`](queries.sql) содержит примеры проверок для условной PostgreSQL-схемы интернет-магазина. Они демонстрируют чтение данных, фильтрацию, `JOIN`, агрегацию и поиск несогласованностей.

## Условная схема

- `products(id, title, price, stock, category_id, is_active)`
- `categories(id, name)`
- `orders(id, user_id, status, total_amount, created_at)`
- `order_items(id, order_id, product_id, quantity, unit_price)`

Запросы не обращаются к данным работодателя и предназначены для чтения. Перед запуском на реальной БД имена таблиц и бизнес-правила нужно сверить со схемой проекта.

## Что проверяется

1. Базовая выборка активных товаров.
2. Связь товара с категорией через `JOIN`.
3. Товары без категории.
4. Нулевой и отрицательный остаток.
5. Дубли названий внутри категории.
6. Расчётная сумма заказа против сохранённой.
7. Ссылочная целостность позиций заказа.
8. Сводка заказов по статусам.
